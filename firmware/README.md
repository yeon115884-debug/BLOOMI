# BLOOMI 펌웨어

꽃 기기(XIAO ESP32-C3)에 들어가는 Arduino 코드예요. 웹(`src/App.tsx`)과는 USB(Web Serial)로 연결됩니다.

| 파일 | 내용 |
|---|---|
| `bloomi_v5/bloomi_v5.ino` | 현재 버전. 심박 + GSR 기준선, 0.5초마다 JSON 출력 |

## 업로드
1. Arduino IDE 2.x → 보드 매니저에서 **esp32 by Espressif Systems** 설치
2. 라이브러리 매니저에서 **Adafruit NeoPixel** 설치
3. `firmware/bloomi_v5/bloomi_v5.ino` 열기 → 보드 **XIAO_ESP32C3**, 포트 선택 → 업로드
4. 웹에서 연결할 때는 **Arduino IDE 시리얼 모니터를 닫기** (포트는 한 프로그램만 사용 가능)

## 배선
| 부품 | XIAO 핀 |
|---|---|
| LED 쥬얼 (7×WS2812) IN | D0 |
| 맥박 센서 S | D1 (A1) |
| Grove GSR SIG (노랑) | D2 (A2) |
| 택트 버튼 | D8 ↔ GND (대각선 다리) |
| 모든 VCC / GND | 3V3 / GND |

## 기기 → 웹 데이터 (115200, 한 줄씩 `\n`)

**0.5초마다 JSON**
```json
{"bpm":74,"gsrRaw":1820,"base":87,"gsrBase":2810,"gsrPct":-4.2,"hrPt":0,"gsrPt":1,"level":0,"state":"G","session":0,"calibrating":0,"calibSec":0,"phase":-1}
```

| 키 | 뜻 |
|---|---|
| `bpm` | 지금 심박 (0 = 측정 안 됨) |
| `gsrRaw` | GSR 원래 값 0~4095 (낮을수록 땀 ↑) |
| `base` / `gsrBase` | 저장된 기준선 (0 = 없음) |
| `gsrPct` | GSR 기준 대비 변화율 % (음수 = 긴장 방향) |
| `hrPt` / `gsrPt` | 심박·GSR 점수 0~2 |
| `level` | 0 초록 / 1 노랑 / 2 빨강 (꽃 LED와 같음) |
| `state` | `N` 손가락없음 `M` 측정중 `G` 초록 `Y` 노랑 `R` 빨강 `B` 호흡 `C` 기준선측정 |
| `session` / `calibrating` | 호흡 중 / 기준선 측정 중이면 1 |
| `calibSec` | 기준선 측정 진행 초 (0~30) |
| `phase` | 호흡 중 현재 단계 번호 (0부터, 호흡 안 할 땐 -1) |

`gsr`(0~100)와 `buttonPressed`는 보내지 않아요. 웹이 `gsrRaw`로 직접 환산하고, 버튼은 아래 문장으로 알려줘서 두 번 처리되는 일을 막아요.

**일이 생길 때 한 줄** (웹의 기존 문구 인식과 같은 문장)
```
>>> 호흡 세션 시작
>>> 호흡 세션 종료
>>> 기준선 측정 시작 (…)
>>> 기준선 측정 취소 (…)
>>> 기준선 측정 실패 (…)
>>> 기준선 저장 완료: 87 BPM / GSR 2810
```
`#`으로 시작하는 줄은 안내용이라 무시하면 돼요.

## 웹 → 기기 명령
| 명령 (`\n`으로 끝남) | 동작 |
|---|---|
| `start` / `stop` | 호흡 안내 시작 / 종료 (웹 호흡 상태가 바뀔 때 자동 전송) |
| `calib` | 기준선 초기화 + 30초 측정 (웹 '기준선 측정' 버튼, 연결 중일 때) |
| `cancel` | 기준선 측정 취소 |
| `pattern:초,밝기,색;…` | 호흡 패턴 바꾸기 (최대 6단계). 웹이 연결 직후·루틴 변경 시 자동 전송 |
| `sync:단계,경과초` | 꽃을 웹 화면의 현재 위치에 맞춤. 웹이 호흡 중 1초마다 자동 전송 |

### 호흡 패턴 형식
```
pattern:4,100,F4A6B8;7,15,B8B5E8;8,100,8FB996
        └ 단계1 ┘ └ 단계2 ┘ └ 단계3 ┘
```
- **초**: 그 단계 길이 (1~30)
- **밝기**: 그 단계가 끝날 때 도달할 밝기 (0~100). 각 단계 동안 이전 단계 끝 밝기에서 이 값으로 서서히 바뀜
- **색**: RRGGBB (생략하면 분홍). 밝기처럼 이전 색에서 서서히 바뀜
- 웹은 루틴의 각 단계를 이렇게 바꿔서 보내요: 화면 꽃이 **펴지는** 단계(`scale ≥ 1`) → 밝기 100, **오므라드는** 단계 → 밝기 15, 색은 단계 색 그대로
- 꽃 버튼으로 시작하면 마지막으로 받은 패턴을 쓰고, 전원을 껐다 켜면 기본(4초 밝아짐 · 2초 유지 · 6초 어두워짐, 분홍)

시리얼 모니터 입력창에 직접 쳐서 테스트할 수도 있어요.

## 버튼 · 판단 규칙
- **짧게**: 호흡 안내 시작/종료 (기준선 측정 중이면 취소)
- **2초 길게**: 기준선 초기화 → 30초 새로 측정 (심박 평균 + GSR 평균 저장, 전원 꺼도 유지)
- 색 = 심박 점수 + GSR 점수
  - 심박: 기준 +7 미만 0점 / +7~+14 1점 / +15 이상 2점
  - GSR: 3% 미만 감소 0점 / 3~8% 감소 1점 / 8% 이상 감소 2점
  - 합계 0~1 초록 · 2 노랑 · 3~4 빨강 (기준선 없으면 심박 85/100 고정값)
- 기준값은 `.ino` 맨 위 상수에서 조정
